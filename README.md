# Netflix-Content-Strategy-Analysis
Exploratory Data Analysis of Netflix content to understand content strategy, ratings, and regional trends using Python
## Overview
This project analyzes Netflix’s content catalog using Python to identify trends in content type, country-wise distribution, ratings, genres, and movie durations.

## Objectives
- Analyze the distribution of Movies vs TV Shows
- Study country-wise content production
- Understand audience targeting using content ratings
- Explore popular genres and movie duration patterns

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Google Colab

## Key Insights
- Movies dominate Netflix’s catalog, but TV Shows have grown significantly over time.
- Content production is concentrated in the United States, India, and the United Kingdom.
- Mature-rated content (TV-MA, TV-14) forms a large portion of the catalog.
- International and Drama genres are the most prevalent.

## Dataset
Netflix Movies and TV Shows dataset
